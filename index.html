RESEARCH OBSERVATION

主张越来越相似，
定位差异在于如何兑现承诺。

“能替你工作”已是这一组竞品的共同表达。真正的区别在于把哪一种价值放在前面：模型与订阅选择、复杂任务执行、工程规范、生态整合，或工作方式的自由。

“手机跟进”和“用户掌控”也不能单独构成独有定位。Happy、Claude Code、Codex、Cursor、Qoder 与 TRAE 已公开说明跨设备使用方式。

BosAgent 值得继续验证的，是能否把工作环境、任务接续、授权和数据边界组织成更清楚、更可信的整体体验。

主张为官网表述的中文概括，定位为研究归纳。
上述判断用于团队讨论，不作为 BosAgent 最终定位。
公开能力未做设备实测或安全审计。

BRAND POSITIONING

BosAgent 品牌主张与定位

安全为本。自由创造。愉悦驾驭。

Secure by design. Free to create. A harness built for joy.

Bosagent 是面向个人与团队的开放式 AI Agent 工作台，以安全为基础，让你安心托付任务，自由决定与 AI 协作的方式。支持自主配置模型与服务，让不同需求与工作习惯都有适合的选择。多个 Agent 围绕你的目标分工协作，将想法推进为成果，让你在创造中保有主导，在完成中收获成就，享受与 AI 一起工作的愉悦。

DESIGN STRATEGY

设计策略

产品价值定位：
Bosagent 是以安全通信为基础的 AI Agent 工作平台，让多个 Agent 围绕目标分工协作，从承接任务到交付成果，开启人与 AI 协同推进工作的新方式
目标客户：
以注重安全与隐私保护的个人和团队为核心，面向更广泛的人与 AI 协作需求
品牌定位：
以隐私保护为基础，把多 Agent 协作打磨得自然顺手的 AI Agent 工作平台
设计目标：
建立鲜明、统一的品牌识别，让“有生命力”贯穿视觉、语言与产品体验
核心价值：
安全、自由、愉悦
风格调性：
品牌个性：有生命力
语言方向：自然、有主见、有趣又专业的合作者

CONCEPT NOTES

晶格／方块 · Lattice

核心概念：由稳定、清晰的基本单元，组成能分工、重组和持续生长的整体。

与产品的关系：

  • 一个单元可以代表一个 Agent
  • 不同单元独立承担任务，通过明确的连接方式协作
  • 组合结构表达共同目标，拆分与重组表达任务分工和成果整合

视觉语言

方形、模块、切角、留白、阵列、嵌合、组合关系。重点是结构与组合的逻辑，不必局限于立体方块。

角色延展：

  • 固定一套基本比例、圆角或切角规则
  • 用轮廓、缺口、模块数量、排列方式区分不同 Agent
  • 可以有克制的眼睛或表情，也可以用姿态和结构变化表达生命感
  • 不能只是同一个方块换颜色；黑白轮廓也应有区别

交互与动效想象

接到目标后展开为多个单元；工作时各自有节奏；交接时传递一个小模块；完成时成果归位并形成清晰整体。

情绪关键词稳固、清晰、灵活、从容。
